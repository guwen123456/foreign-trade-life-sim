# 外贸人生模拟器 · Foreign Trade Life Simulator

一款文字选择类人生模拟游戏：24 岁，存款 ¥30000，你拖着行李箱来到深圳做外贸。接下来 5 年怎么过，你说了算。

## 在线试玩

**https://guwen123456.github.io/foreign-trade-life-sim/**

手机/电脑浏览器打开即玩，单局约 10 分钟。

## 玩法

- 五维属性：💰 现金、🤝 客户、⭐ 口碑、🔋 精力、🎓 经验
- 每个月选一个行动：开发客户 / 跟进订单 / 学习提升 / 展会跑工厂 / 休息调整
- 20+ 个真实外贸事件随机触发：深夜 WhatsApp 询盘、工厂涨价、客户压价、验货次品、海运费暴涨、汇率过山车、客户拖款、猎头挖角、TikTok Shop 风口、家里催你回家、存款够了要不要创业单干……
- 支线系统：升职加薪、跳槽、开平台店、TikTok 副业、自己当老板（收益翻倍但没底薪）
- 7 种结局：外贸大亨 / 稳健老板 / 金牌业务员 / 平凡外贸人 / 月光外贸人 / 健康退休 / 跑路结局
- 红线：现金低于 -¥10000 破产；精力耗尽会病倒，病倒 3 次影响结局

## 技术

- 单文件 `index.html`（HTML + CSS + JS），零依赖零构建
- 背景音乐与音效由 WebAudio 实时合成，无音频素材、无版权风险
- 纯离线单机，不联网、不收集任何信息、无内购
